# Getting Started

1. Download the latest zip from the repository's **Releases** page and move **Foyer.app** to
   Applications.
2. Release builds are ad-hoc signed. The first time, right-click the app and choose **Open**, or allow
   it in **System Settings ▸ Privacy & Security**.
3. On first launch Foyer installs three legal add-ons: **Cinemeta**, **The Movie Database** and
   **OpenSubtitles v3**. Home fills with Trending Now and catalog rows.
4. Add more in **Settings ▸ Add-ons** (⌘,), from the suggestions or by pasting a manifest URL.

## Where things are

| Sidebar | What it shows |
|---|---|
| Search | Search field, Recently Searched, Browse Categories |
| Home | Hero, Trending Now, Continue Watching, catalog rows |
| Movies / TV Shows | The same for one type, plus genre chips |
| Library | Recently Added, saved Movies and TV Shows |
| Settings | Add-ons, playback, subtitles, library, storage, about |

Your data stays on your Mac in `~/Library/Application Support/Foyer/`.
