# Keyboard Shortcuts

## App

| Keys | Action |
|---|---|
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | Home / Movies / TV Shows / Search |
| ⌘F | Search |
| ⌘R | Reload the page |
| ⌘, | Settings |
| ⌃⌘S | Show or hide the sidebar |

## Player

| Keys | Action |
|---|---|
| Space, ⌘↩ | Play / Pause |
| ← / → | Back / forward 10 s (⌘← / ⌘→ from the Playback menu) |
| ↑ / ↓ | Volume (⌘↑ / ⌘↓ from the menu) |
| M, ⌥⌘↓ | Mute |
| F, double-click | Full screen |
| Esc | Leave full screen |
| Click on video | Show / hide controls |
